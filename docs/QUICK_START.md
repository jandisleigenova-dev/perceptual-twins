# Quick Start — 5 minutes

## Research question

When an active agent appears epistemically better, **what caused the advantage**?

The Perceptual Twins design separates:

1. prospective action metadata (`tau_tag`);
2. adaptive epistemic experiment selection (`tau_select`);
3. correct command–consequence coupling (`tau_couple`);

while treating E/C_E execution equivalence as an implementation diagnostic.

```bash
python reference_implementation/perceptual_twins_synthetic_poc.py --output-dir outputs
```
