# Scope and Non-Claims

The replication kit is deliberately narrow.

A successful reproduction supports only the following statement:

> The released deterministic reference implementation reproduces the reported synthetic estimand-recovery results under its declared configuration.

It does **not** establish:

- general epistemic autonomy;
- causal-ontological autonomy across architectures;
- necessity of active developmental experience;
- external validity to physical robots;
- consciousness;
- moral agency;
- legal personhood;
- independent liability.

The full manuscript explicitly treats these as separate questions.
