# Release Notes — Perceptual Twins Replication Kit v1.0

**Public release date:** 12 August 2026  
**Accompanying manuscript:** version 2.1.1, 5 August 2026  
**Release status:** stable v1.0 replication package

## Purpose

This release makes the synthetic proof-of-concept independently reproducible while preserving the exact version 2.1.1 reference implementation and expected outputs.

## What v1.0 establishes

- deterministic reproduction of the released synthetic estimand-recovery study;
- recovery of the published paired contrasts under the declared configuration;
- exact E/C_E implementation-equivalence diagnostic in the reference study;
- a documented, inspectable code and reporting path for third-party replication.

## What v1.0 does not establish

- validation of the full Perceptual Twins Benchmark across architectures;
- general task-relative epistemic autonomy;
- physical-robot replication;
- consciousness, moral agency, or legal personhood.
