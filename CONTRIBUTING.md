# Contributing

Scientific replication, criticism, falsification attempts, bug reports, and improvements are welcome.

## License of contributions

Unless you explicitly state otherwise, any contribution intentionally submitted for inclusion in the software portion of this project is submitted under the Apache License 2.0, consistent with Section 5 of that license.

Contributions to documentation should be submitted under CC BY 4.0.

## Scientific integrity

Please separate:

- reproduction of the released v2.1.1 synthetic study;
- modifications to the reference implementation;
- extensions of the benchmark;
- empirical claims about agent capability.

Modified files must be clearly identified. Negative and null results are welcome. Do not relabel a modified experiment as the unchanged v2.1.1 reference study.
